# Mizuyori

Локальное веб-приложение: запускается на вашем компьютере и открывается в браузере.

## Запуск

Двойной клик по `Mizuyori.bat`. Браузер откроется сам.

## Главная

| Где | Что |
|---|---|
| слева | часы, под ними календарь (клик по месяцу — вернуться к сегодняшнему дню) |
| по центру | чат: Enter — отправить, Shift+Enter — новая строка |
| справа | «Дела»: задачи и заметки |

- **Задачи:** у задачи может быть срок и список. Группы: «Просрочено», «Сегодня», «Завтра», «Позже», «Без срока», «Выполнено».
  Галочка — выполнено, клик по задаче — изменить (текст, срок, список), крестик — удалить.
- **Списки задач:** «Дом», «Работа», «Покупки» и свои — с цветом и значком. Фишки над задачами фильтруют по списку, кнопка справа от них — настроить списки.
- **Календарь и задачи:** точка под числом — на этот день есть задачи. Клик по дню показывает задачи на этот день, новая задача получает эту дату. Повторный клик — снова все дни.
- **Заметки:** первая строка — заголовок; Ctrl+Enter — сохранить, Esc — закрыть.
- **ИИ** в чате пока не подключён (будет без Ollama). Подключается в одном месте — `mizuyori/ai.py`.

Настройки проекта — значок шестерёнки в левом верхнем углу сайта.

Чтобы остановить — закройте чёрное окно или нажмите `Ctrl+C`.

### Что происходит при первом запуске

- Если установлен Python 3.10+, создаётся окружение `.venv`.
- Если Python нет, в папку `python` скачивается портативный Python 3.12 (около 11 МБ, без установки и прав администратора).
- Ставятся зависимости из `requirements.txt`. Потом — только если этот файл изменился.
- Создаются `config.json`, папки `data` и `logs`.

Папку проекта можно положить куда угодно: пробелы, скобки и русские буквы в пути не мешают.

## Настройки — `config.json`

| Настройка | Что делает | По умолчанию |
|---|---|---|
| `имя` | название в заголовке страницы | `Mizuyori` |
| `внешний_вид` | цвета, шрифт, углы и прочее — удобнее менять на сайте | см. ниже |
| `порт` | с какого порта начинать; если занят, берётся следующий свободный | `8000` |
| `открывать_браузер` | открывать браузер сам при запуске | `true` |
| `доступ_из_сети` | `true` — открывать с телефона и других устройств в той же сети | `false` |

### Внешний вид

Значок шестерёнки в левом верхнем углу сайта открывает «Настройки проекта».
Изменения сразу видны на сайте, а сохраняются кнопкой «Сохранить».
«Отменить» возвращает сохранённый вид, «Сбросить внешний вид» — начальный.

| Настройка | Варианты |
|---|---|
| Цвет сайта | тёмно-чёрный, золото, янтарь, нефрит |
| Вариант темы | тёмный, светлый |
| Яркость фона | глубже, обычная, светлее |
| Размер шрифта | мелкий, обычный, крупный |
| Скругление углов | острые, мягкие, круглые |
| Плотность | компактно, обычно, просторно |
| Цветные заголовки | вкл / выкл |
| Матовое стекло | вкл / выкл |

Если файл испорчен, он сохраняется как `config.broken.json`, а вместо него создаётся новый.

## Где что лежит

| Путь | Что это |
|---|---|
| `Mizuyori.bat` | запуск |
| `tools/launch.ps1` | поиск или скачивание Python, установка зависимостей |
| `main.py` | точка входа программы |
| `mizuyori/` | код: сервер, настройки, база, журнал |
| `mizuyori/ai.py` | ИИ для чата (пока заглушка) |
| `mizuyori/static/` | страница: `index.html`, `style.css`, `app.js` (общее и настройки), `clock.js` (часы и календарь), `chat.js` (чат), `tasks.js` (дела) |
| `data/mizuyori.db` | база данных SQLite |
| `logs/mizuyori.log` | журнал работы и ошибок |

Названия файлов и адреса — латиницей: кириллица в них ломает распаковку zip в Windows и ссылки.
Всё остальное — интерфейс, сообщения, журнал, настройки, комментарии — на русском.
