# Mizuyori

## Запуск

Двойной клик по `Mizuyori.bat`.

- Если установлен Python 3.10+, создаётся виртуальное окружение `.venv`.
- Если Python нет, в папку `python` скачивается портативный Python (~11 МБ, без установки и прав администратора).
- Зависимости из `requirements.txt` ставятся при первом запуске и потом, только если файл изменился.

Папку проекта можно класть куда угодно: пробелы, скобки и русские буквы в пути не мешают.
