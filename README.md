# Mizuyori

## Запуск

Двойной клик по `Mizuyori.bat`.

При первом запуске создаётся виртуальное окружение `.venv` и ставятся зависимости из `requirements.txt`.
Потом они переустанавливаются только если `requirements.txt` изменился.

Нужен Python 3.10+ (с галочкой «Add Python to PATH» при установке).
