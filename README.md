# Mizuyori

Локальное веб-приложение: запускается на вашем компьютере и открывается в браузере.

## Запуск

Двойной клик по `Mizuyori.bat`. Браузер откроется сам.

## Главная

| Где | Что |
|---|---|
| слева | часы, календарь (клик по месяцу — вернуться к сегодняшнему дню) |
| по центру | чат: Enter — отправить, Shift+Enter — новая строка |

**Чат.** Ответы ИИ с разметкой — жирный, курсив, списки, заголовки, код с кнопкой «Копировать», таблицы;
звёздочек `**` на экране нет. Ответ печатается плавно, целыми словами, новые сообщения мягко появляются.
Под ответом: **➕ В задачи** (пункты списка из ответа или выделенный текст — галочки, срок, список),
**🎯 В цель** (название из заголовка или выделения, можно сразу с шагами-задачами), **✎ В заметку**, **⧉ Копировать**.

Клик по дню в календаре открывает экран «Дела» с задачами на этот день.

**Агенты** — справа от чата, сверху вниз по ходу работы, по группам (Общение, Память, Дела и цели, Душа; группы сворачиваются): Собеседник → Память → Смысл → Летописец → Стратег → Душа. У каждого — состояние и последний результат.
Когда один берётся за дело после другого, по дорожке между ними летит искра; закончил — вспышка
(зелёная — успех, красная — ошибка). Кольцо крутится, пока агент работает, дуга — сколько раз за сегодня,
звёздочки — уровень.

- **Клик по агенту** — окно: уровень и опыт, **история решений** (что сделал, почему, результат, поиск),
  **своя память** (правила и приёмы — пишете вы, они добавляются к заданию агента; частые ошибки — собирает сам),
  **записки** этому агенту.
- **Опыт** растёт от полезных действий (новые факты, связи, привязки, мнения): уровни на 10, 30, 70, 150 опыта.
- **Доска** — записки агентов друг другу: Память пишет Стратегу и Душе о новой цели — Стратег сам раскладывает
  задачи, Душа обновляет мнения. Можно написать агенту и самому.

## Дела

Отдельный экран в меню. Вверху — кольцо «сколько сделано на сегодня» и виды:

| Вид | Что |
|---|---|
| Список | задачи по группам и заметки |
| Доска | колонки «Просрочено», «Сегодня», «Завтра», «На неделе», «Позже», «Без срока», «Выполнено»; перетащите карточку — срок поменяется сам, «+» в колонке — быстрая задача |
| Неделя | дни с понедельника по воскресенье, перетаскивание между днями, стрелки — соседние недели |
| Цели | карточки целей с кольцом прогресса, шагами-задачами, «+ шаг», «Цель достигнута», новая цель; «Разложить по целям (ИИ)» |
| Заметки | заметки |

Клик по карточке — окно правки: текст, срок (быстрые кнопки «Сегодня», «Завтра», «Выходные»), список, цель, выполнено, удалить.

- **Задачи:** у задачи может быть срок и список. Группы: «Просрочено», «Сегодня», «Завтра», «Позже», «Без срока», «Выполнено».
  Галочка — выполнено, клик по задаче — изменить (текст, срок, список), крестик — удалить.
- **Списки задач:** «Дом», «Работа», «Покупки» и свои — с цветом и значком. Фишки над задачами фильтруют по списку, кнопка справа от них — настроить списки.
- **Календарь и задачи:** точка под числом — на этот день есть задачи. Клик по дню показывает задачи на этот день, новая задача получает эту дату. Повторный клик — снова все дни.
- **Заметки:** первая строка — заголовок; Ctrl+Enter — сохранить, Esc — закрыть.
- **ИИ в чате** — через cloud.ru (Evolution Foundation Models), ответ печатается по мере генерации.

## Работа

Раздел в меню для отдела: слева разделы, справа таблица. Клик по строке — правка, «+» — новая запись,
«⬇ Excel» — выгрузка любого списка.

| Раздел | Что |
|---|---|
| Сотрудники | ФИО, должность, табельный №, телефон; закрепляется **топливная карта** и **автомобиль** |
| Автомобили | марка, модель, госномер, топливо, расход лето / зима (л/100 км), ОСАГО и техосмотр до, ТО (каждые N км, пробег и дата последнего), шины, водитель. **Напоминания** сверху: ОСАГО, техосмотр — за 30, 14 и 3 дня и после срока; ТО по пробегу из путевых («до ТО 1 500 км»); смена шин к сезону. Клик по машине — **история по месяцам** с графиком: пробег, норма, факт, заправки, остаток |
| ГСМ | загрузка **выписки по топливным картам** (.xls/.xlsx, как у поставщика: «Карта № …», «Отгрузка / Возврат»); свод по картам — водитель, авто, литры по видам топлива, сумма, операции; клик — все заправки карты; повторная загрузка не задваивает |
| ГСМ → Путевые листы | расчёт по норме и по факту за месяц для каждой машины: км и остаток на начало (первая путевая), км на конец (последняя), расход по факту (не записан — равен норме), **остаток на конец считается сам**, сезон лето/зима (по умолчанию зима с ноября по март), заправлено по карте водителя + не по карте; перерасход красным, экономия зелёным; «Начало = конец прошлого месяца» |
| Топливные карты | номер, поставщик, лимит; карты из выписки добавляются сами — останется закрепить за сотрудником |
| Табель | месяц × сотрудники, коды Я, В, ОТ, Б, К, ДО, НН, РВ и часы; **норма месяца** (дни и часы); «Заполнить пустые» — по **производственному календарю** (праздники, переносы, рабочие субботы, сокращённые дни по 7 ч); **«+ Отпуск / больничный / командировка»** — период с датами, табель заполняется сам (праздники в отпуск не входят), убрать период — вернётся обычный график |
| Служебные записки | номер (по порядку за год), дата, кому, от кого, тема, текст, статус; **печать** готовым бланком |
| Договоры | №, дата, контрагент, ИНН, предмет, сумма, срок действия (⚠ за 30 дней до конца), статус |
| Счёт-оферты | договор и счёт в одном: №, поставщик, за что, сумма, оплатить до (⚠ просрочено), оплачено |

**Производственный календарь** зашит на 2026 и 2027 год (постановления Правительства РФ № 1466 от 24.09.2025 и № 1187
от 17.09.2026). Хранятся текущий и следующий год: когда наступит 2027-й, календарь 2026 года удалится сам.

**Сезоны** для норм — по датам (по умолчанию зима с 01.11 по 31.03, меняется кнопкой «изменить» в путевых листах).
Если граница внутри месяца, норма считается частями по дням («зима 16 дн. + лето 14 дн.»). Начало месяца
(км и остаток) подставляется само из конца прошлого.

**Путевые листы:** пробег = км конец − км начало; по норме = пробег × норма (лето/зима из карточки автомобиля) / 100;
по факту — из путевых (не записан — равен норме); остаток на конец = остаток на начало + заправлено − расход по факту;
отклонение = факт − норма. Выгрузка в Excel — с формулами,
можно поправить цифры прямо в Excel.

**Выгрузка ГСМ в Excel** — три листа: «Свод» (карта, водитель, должность, автомобиль, госномер, литры по видам
топлива, всего, сумма, операций, итоги формулами), «Выписка» (как у поставщика, но с водителем и авто у каждой карты),
«По видам топлива». **Табель в Excel** — сетка месяца с днями недели, выходные подсвечены, итоги дней и часов.

## ИИ через cloud.ru

1. В личном кабинете cloud.ru: Пользователи → Сервисные аккаунты → аккаунт → «Создать API-ключ»,
   сервис — **Foundation Models**. Сохраните Key Secret — второй раз его не покажут.
2. На сайте: шестерёнка → вкладка **«ИИ · cloud.ru»** → вставьте ключ → «Проверить».
   Подтянется список моделей, доступных по ключу.
3. Выберите модель, при желании — температуру, длину ответа, память чата и характер. «Сохранить».
4. «Проверить ответ» — короткий пробный запрос к модели.
5. «Модель для смысловых связей» — эмбеддинги (например, `Qwen/Qwen3-Embedding-0.6B`) для «Мозгов».

**Память ИИ.** Устроена как у человека — долговременная и краткосрочная.

- *Долговременная* — факты о вас с категорией (о себе, люди, работа, здоровье, предпочтения, планы, даты, другое)
  и важностью 1–5. После каждого ответа ИИ в фоне решает: добавить новый факт, **заменить** старый,
  если вы что-то уточнили или изменилось («переехал в Москву» заменяет «живёт во Владивостоке»),
  или удалить («забудь про…»). Почти одинаковые факты не дублируются.
- *Умный выбор:* в ответ идут не все факты, а важные (4–5) и 12 самых близких по смыслу к вопросу —
  ИИ не путается, даже когда фактов сотни (нужна модель эмбеддингов).
- *Краткосрочная* — сводка: сообщения, вышедшие за «память чата», сжимаются в пересказ,
  и ИИ не теряет нить длинного разговора. И рабочая память: тема разговора, что уже решили,
  какие вопросы открыты.

**Понимание: кто, что, для кого, зачем, почему.** ИИ хранит не просто фразы, а понимает связи:

- у факта есть *смысл* по полям: кто, что, для кого, зачем, почему, когда;
- *сущности* — люди, питомцы, места, организации, проекты, цели, события, вещи (у людей — другие имена:
  «Мама», «мамуля»); *связи* между ними с подписью («Мама → любит → зелёный чай»);
- *цели* отдельно от причин и шагов: у цели есть «почему» и статус, цепочки причин —
  связи «потому что» / «чтобы» («Выучить японский → потому что → поездка → потому что → мечта»);
- *задачи привязываются к целям*: ИИ делает это сам по разговору, вручную — в правке задачи (поле «Цель»),
  всё сразу — кнопка «🎯 К целям» внизу задач;
- в ответах ИИ опирается на понимание («что подарить маме?» → вспомнит, что она любит, и когда день рождения),
  а если неясно, для кого или зачем, — один раз уточнит.

В «Мозгах»: раскладка **«Понимание»** — в центре «Я», вокруг цели, у целей шаги-задачи, дальше люди и места,
связи подписаны, причинные — пунктиром. **Карточка сущности** — связи, факты, задачи, заметки, упоминания в чате;
у цели — «Цель достигнута ✓». **Путь «почему»** — у задачи светится цепочка до цели и её причин.
**Поиск по связям** — «мама» найдёт всё, что связано с мамой.

В настройках ИИ: факты по категориям, важность — клик по точкам, категория — выпадающий список,
блок «Сейчас в разговоре» с пересказом ранней части чата. В «Мозгах» факты сгруппированы по категориям
(важные — крупнее), рабочая память мерцает на орбите «Сейчас» вокруг ядра.

Ключ хранится только в `config.json` на этом компьютере (файл не попадает в git) и на страницу целиком не отдаётся.
Адрес API (по умолчанию `https://foundation-models.api.cloud.ru/v1`) можно поменять в «Дополнительно» —
подойдёт любой OpenAI-совместимый сервис.

## Мозги

Меню в шапке: «Главная» и «Мозги». Мозги — всё, что знает Mizuyori, в виде живого графа:
в центре ядро, вокруг разделы (Задачи, Заметки, Чат или списки задач), в них группы и точки.

- **Раскладки:** кольца (медленно вращаются), круг, соты, сила (пружины),
  плата (разделы — микросхемы, к ним от ядра идут дорожки) и HUD (кольца-дорожки, шкала, луч радара).
- **Память ИИ:** раздел с фактами, которые ИИ запомнил о вас (ромбики). Клик по факту → «Забыть этот факт».
- **Смысловые связи:** похожие по смыслу задачи, заметки и факты соединены линиями.
  Считаются эмбеддингами cloud.ru (модель выбирается в настройках ИИ), хранятся в базе —
  пересчитываются только изменённые тексты. Порог похожести — ползунок на панели.
  В карточке точки — список «Похожее по смыслу».
- **Значки:** люди, цели, места и проекты (раздел «Понимание») — кружки с символом: в кольцах — на внешнем
  кольце, в сотах — в щелях между шестиугольниками. Вокруг ядра — зубчатое кольцо, под ядром — имя.
- **Агенты на графе:** внешнее кольцо «Агенты» — значки агентов со звёздами уровня. От каждого тянутся нити
  к разделам, с которыми он работает (Память → Память ИИ и Понимание, Собеседник → Чат и «Сейчас»…).
  Пока агент работает, значок светится, по нитям бегут огоньки, раздел отзывается кольцом.
  Наведение — что делает и последний результат, клик — окно агента. Выключается флажком «Агенты на графе».
- **Блоки-матрицы:** группы в кольцах — ровные блоки точек, пустые места — тусклые точки.
- **Наведение на раздел:** остальное гаснет, к точкам раздела бегут огоньки, в подсказке — группы и их размер.
- **Вид:** «Разделы» или «Списки» (каждый список задач — свой раздел, внутри — по срокам).
- **Мышь:** тянуть — двигать, колесо — приближать, наведение на раздел — связи к его точкам.
  Клик по разделу — выделить, двойной клик — свернуть. Клик по точке — карточка с кнопкой «Открыть».
- **Поиск:** клавиша `/`, Enter — к первой найденной точке, Esc — сбросить.
- **Панель:** ползунки вращения, пружин и размера; «Развернуть / Свернуть всё», «В центр»,
  «Сохранить настройки» (в `config.json`), «Скачать PNG».

### Душа

Вкладка «♡ Душа» рядом с «Граф». В центре светящееся ядро: дышит в такт энергии,
цвет — от настроения. Вокруг по орбитам летают черты, ценности и границы.

- **Суть, черты, ценности, границы, манера речи** — кнопка «Изменить», фишки добавляются Enter-ом
  (до 8 в каждом разделе), «Вернуть исходную душу» — к начальным.
- **Настроение** считается из ваших дел и разговоров: всё на сегодня сделано — радуется,
  только что говорили — воодушевлена, 3 и больше просрочек — беспокоится, давно не говорили — скучает.
  Причины показаны в карточке.
- **Мы знакомы:** дни, сообщения, факты, сколько всего в понимании.
- **Нити к важному:** от ядра тянутся нити к активным целям (🎯 с кольцом прогресса), проектам (📁) и людям (👤),
  по нитям бегут огоньки; чем важнее — тем ярче. Наведение — её мнение об этом, клик — карточка мнения.
- **Мнения:** что она честно думает о ваших целях и проектах (радуюсь, верю, сомневаюсь, беспокоюсь) и почему.
  Обновляются сами раз в день после разговора или кнопкой «Обновить»; лишнее — крестиком.
- **Мысли:** перед ответом ИИ коротко думает про себя. В чате над ответом значок «💭 мысль» —
  клик раскрывает, о чём она подумала. Выключается в карточке «Мысли».
- **Переход:** при переключении граф сворачивается в ядро, из ядра раскрывается душа, и обратно.
- Душа, настроение и мнения добавляются к каждому ответу ИИ. Хранятся в базе.

Настройки проекта — значок шестерёнки в левом верхнем углу сайта.

Чтобы остановить — закройте чёрное окно или нажмите `Ctrl+C`.

### Что происходит при первом запуске

- Если установлен Python 3.10+, создаётся окружение `.venv`.
- Если Python нет, в папку `python` скачивается портативный Python 3.12 (около 11 МБ, без установки и прав администратора).
- Ставятся зависимости из `requirements.txt`. Потом — только если этот файл изменился.
- Создаются `config.json`, папки `data` и `logs`.

Папку проекта можно положить куда угодно: пробелы, скобки и русские буквы в пути не мешают.

## Настройки — `config.json`

| Настройка | Что делает | По умолчанию |
|---|---|---|
| `имя` | название в заголовке страницы | `Mizuyori` |
| `внешний_вид` | цвета, шрифт, углы и прочее — удобнее менять на сайте | см. ниже |
| `порт` | с какого порта начинать; если занят, берётся следующий свободный | `8000` |
| `открывать_браузер` | открывать браузер сам при запуске | `true` |
| `доступ_из_сети` | `true` — открывать с телефона и других устройств в той же сети | `false` |

### Внешний вид

Значок шестерёнки в левом верхнем углу сайта открывает «Настройки проекта».
Изменения сразу видны на сайте, а сохраняются кнопкой «Сохранить».
«Отменить» возвращает сохранённый вид, «Сбросить внешний вид» — начальный.

| Настройка | Варианты |
|---|---|
| Цвет сайта | тёмно-чёрный, золото, янтарь, нефрит |
| Вариант темы | тёмный, светлый |
| Яркость фона | глубже, обычная, светлее |
| Размер шрифта | мелкий, обычный, крупный |
| Скругление углов | острые, мягкие, круглые |
| Плотность | компактно, обычно, просторно |

## Где что лежит

| Путь | Что это |
|---|---|
| `Mizuyori.bat` | запуск |
| `tools/launch.ps1` | поиск или скачивание Python, установка зависимостей |
| `main.py` | точка входа программы |
| `mizuyori/` | код: сервер, настройки, база, журнал |
| `mizuyori/ai.py` | ИИ для чата: cloud.ru, список моделей, ответ потоком |
| `mizuyori/work.py` | «Работа»: справочники, импорт выписки ГСМ, табель, выгрузки в Excel |
| `mizuyori/agents.py` | агенты: кто работает, сколько раз сегодня, последняя ошибка |
| `mizuyori/soul.py` | душа ИИ: характер, ценности, границы, настроение |
| `mizuyori/memory.py` | память ИИ: выбор фактов по смыслу, обновление после ответа, сводка чата |
| `mizuyori/static/` | страница: `index.html`, `style.css`, `app.js` (общее и настройки), `clock.js` (часы и календарь), `chat.js` (чат), `markdown.js` (разметка ответов), `tasks.js` (список дел и заметки), `deals.js` (экран «Дела»: доска, неделя, цели), `work.js` (экран «Работа»), `brain.js` (мозги), `soul.js` (вкладка «Душа»), `agents.js` (агенты на главной), `ai-settings.js` (настройки ИИ) |
| `data/mizuyori.db` | база данных SQLite |
| `logs/mizuyori.log` | журнал работы и ошибок |

Названия файлов и адреса — латиницей: кириллица в них ломает распаковку zip в Windows и ссылки.
Всё остальное — интерфейс, сообщения, журнал, настройки, комментарии — на русском.
