Сюда кладутся ваши образцы путевых листов (Excel, .xlsx / .xls).
Имя файла: «<машина> - <водитель>.xlsx», например «TOYOTA HILUX - Иванов Иван Иванович.xlsx».

Файлы из этой папки в git не попадают (в них ФИО водителей и госномера),
поэтому при переносе проекта на другой компьютер копируйте папку вручную.
