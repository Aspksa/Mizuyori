Сюда можно положить свои образцы документов (Word, .docx) — агенты будут заполнять их вместо встроенных:

  служебная_записка.docx   — Старший инженер
  дефектовая_ведомость.docx — Механик по выпуску
  договор.docx             — Юрист (если сумма сметы не меньше порога из config.json → «агенты»)
  счёт_оферта.docx         — Юрист (если сумма меньше порога)

В тексте образца поставьте метки в двойных фигурных скобках, они заменятся данными сметы:
  {{объект}} {{исполнитель}} {{заказчик}} {{номер}} {{дата}} {{итого}} {{ндс}} {{сегодня}}
  {{тема}} {{текст}} — только для служебной записки (тема и текст, написанные агентом)
  {{таблица}} — на этом месте вставится таблица работ и материалов (отдельным абзацем)
Чего нет в смете, подставится как «[не указано]». Если файла нет, берётся встроенный бланк.
